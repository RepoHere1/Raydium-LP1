Raydium-LP1

Extreme APR LP scanner

This project scans Raydium pool data, flags APRs at or above your setting (default 999.99%), and applies local safety filters before any future LP automation is considered.

Current build is dry-run only: no wallet keys, no signing, no buys.

With the local stack running (scripts\start_stack.cmd), open the funnel UI, positions-style table, or this page inside the server.

Double-click START_HERE_SETUP.bat or run .\setup_wizard.ps1
